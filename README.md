# dsh-voice-push

给 DeepSeek Harness 用的**按住说话 + 一键朗读**插件。

连按两次 `Alt` 开始录音，说话，松开 `Alt` 自动把识别结果发出去；
回复可以自动朗读，也可以设一个自己的快捷键，按一下就读出来。

> 本项目 fork 自 [dsh-voice-chat](https://github.com/maoyuching/dsh-voice-chat)（MIT）。
> 主要改动：换了包名和路由前缀、把快捷键改成「连按两次开始、松开发送」、新增可自定义的朗读快捷键。

---

## 功能

**语音输入**
- 连按两次 `Alt` 开始录音，松开 `Alt` 结束并自动发送（可在设置里关掉自动发送）
- 静音超过设定秒数也会自动结束
- 识别结果追加到输入框，不覆盖你已经在打的字

**朗读**
- 回复完成后自动朗读（可关）
- 可自定义一个朗读键：按一下就朗读最新一条回复
- 按空格暂停 / 继续当前朗读
- 输入框旁的喇叭按钮一键静音 / 恢复

**识别与合成引擎**
- ASR：硅基流动 SiliconFlow（默认）、Groq Whisper、小米 MiMo、任意 OpenAI 兼容接口
- TTS：微软 Edge TTS（免费）、小米 MiMo、任意 OpenAI 兼容接口

---

## 安装

```bash
dsh plugin --profile desktop add dsh-voice-push
```

装完**完全退出 DSH 再重开**（关窗口不算，从菜单或托盘退出）。

---

## 配置

装好后进 DSH 的插件设置，找到「语音对话」，填两样东西：

### 1. ASR 密钥（必填，否则语音输入不能用）

默认用硅基流动，去 <https://cloud.siliconflow.cn> 注册，在「API 密钥」页面创建一个，复制以 `sk-` 开头的字符串填进「ASR API Key」。

模型留空即可，默认 `FunAudioLLM/SenseVoiceSmall`，中文识别效果不错，价格便宜。

不想用硅基流动，也可以切到 Groq（要 Groq 的 key）或任何 OpenAI 兼容的 `/audio/transcriptions` 接口。

### 2. 朗读（可选）

Edge TTS 不需要密钥，默认就能用（走微软的在线语音合成，需要联网）。

音色可以换成任意 Edge 音色，`zh-CN-XiaoxiaoNeural`（晓晓）是默认值。

### 3. 朗读快捷键（可选）

设置面板里有一栏「朗读快捷键」，点进去直接按下你要的键（比如 `F8`，或 `Control+Shift+R`）。

之后按这个键，就会朗读最新一条回复。留空则不启用。

> 注意：焦点在输入框里时按键不会触发，点一下消息区再按。

## 常见问题

**按两次 Alt 没反应？**
先确认焦点不在输入框里；再看设置里 ASR 密钥填了没有。第一次录音浏览器会弹麦克风权限，允许即可。

**朗读没声音？**
Edge TTS 需要联网。检查网络，或者换成自定义 TTS（填一个 OpenAI 兼容的 `/audio/speech` 地址）。

**Alt 键会不会和别的软件冲突？**
Alt 单独按键在 Windows 上会触发菜单栏。本插件用「连按两次」来规避这个问题；如果还是冲突，可以在设置里改用别的组合键（插件本身用的是 `Alt` 双击，暂不支持改这个键位）。
